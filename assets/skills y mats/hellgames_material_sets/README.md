# Hell Games - Sets de materiales

Imagenes generadas para recursos y materias primas del juego.

Fuentes revisadas:

- `HELL_GAMES_OBJETOS_RECURSOS.md`
- `doc_materiales1.md`
- `HELL_GAMES_RECETAS_CRAFTING.md`

## Archivos derivados

- `icons_cells/`: 64 PNG separados, uno por cada celda exacta de las hojas.
- `icons_by_id/`: 62 PNG unicos por ID de material. `piedra_comun` y `piedra_filosa` aparecen en dos hojas, por eso hay menos IDs unicos que celdas.
- `icons_index.json`: indice de celdas e iconos por ID.
- `guide/GUIA_MATERIALES_HELLGAMES.md`: guia editable en Markdown.
- `guide/GUIA_MATERIALES_HELLGAMES.pdf`: guia visual en PDF.
- `guide/material_guide_data.json`: datos estructurados de jerarquia, uso, fabricacion y ubicaciones.

Orden de celdas: izquierda a derecha, arriba hacia abajo.

## Prompt base usado

Hojas de iconos de inventario RPG 2D, estilo supervivencia fantastica, 4x4 celdas, fondo oscuro, sin texto, un material por celda, siluetas claras y texturas legibles para objetos de crafting.
