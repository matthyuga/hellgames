# Hell Games - Knowledge Sets

Set de iconos para libros, manuales, folletos, hojas, recetas y materiales de escritura.

## Archivos principales

- `hellgames_conocimiento_01_libros_manuales.png`: 16 libros, manuales y documentos de conocimiento.
- `hellgames_conocimiento_02_escritura_documentos.png`: 16 materiales de escritura y documentos creados.
- `knowledge_sets_manifest.json`: orden exacto de celdas.
- `icons_cells/`: recortes por celda y set.
- `icons_by_id/`: recortes normalizados por ID.
- `icons_index.json`: indice para consumo del bot o guias.
- `guide/GUIA_LIBROS_HABILIDADES_HELLGAMES.md`: guia editable de libros, habilidades y escritura.
- `guide/GUIA_LIBROS_HABILIDADES_HELLGAMES.pdf`: guia en PDF.
- `guide/knowledge_guide_data.json`: datos consolidados de la guia.
- `guide/knowledge_icons_contact.png`: hoja contacto de iconos.

## Logica de juego

Estos iconos corresponden al sistema documentado en `HELL_GAMES_LIBROS_HABILIDADES_RECETAS.md`.
La regla central es que los libros desbloquean conocimiento, la escritura lo transfiere, y la practica lo vuelve confiable.

El carbon vegetal puede usarse para marcas o apuntes toscos, pero para recetas claras conviene convertirlo o elegir `carboncillo`, `lapiz`, `lapicera` o `pluma` + `tinta`.
