# Hell Games - Scenario Art

Carpeta con 25 imagenes generadas para los escenarios de la isla.

- `escenario_01_*.png` a `escenario_25_*.png`: arte propio de cada escenario.
- `contact_sheet_escenarios.png`: hoja de contacto para revisar todas juntas.
- `manifest_escenarios.json`: indice con nombre, recorte del mapa y arte generado.

Estilo usado:

```text
Dark fantasy survival board-game concept art, painterly 3/4 isometric
environmental view, square composition, no text, no UI, no numbers,
environment-focused, readable as Discord embed artwork.
```

Estas imagenes son assets de trabajo. Para despliegue en Discloud conviene no
meterlas en el ZIP del bot si se van a subir a Discord como adjuntos persistentes.
