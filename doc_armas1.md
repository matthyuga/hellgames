Perfecto. Conviene que este hilo sea el **catálogo maestro de armas del Battle Royale**, separado por tipos, rareza, munición, daño, ruido y utilidad narrativa.

Podemos ordenar cada arma con esta ficha base:

## Ficha de arma

**Nombre:**
**Tipo:** cuerpo a cuerpo / distancia / improvisada / trampa / explosiva / especial
**Rareza:** común / poco común / rara / épica / legendaria
**Daño:** bajo / medio / alto / letal
**Ruido:** silenciosa / bajo / medio / alto
**Riesgo de uso:** bajo / medio / alto
**Durabilidad:** baja / media / alta
**Requiere habilidad:** sí/no
**Habilidades relacionadas:** fuerza, puntería, sigilo, supervivencia, mecánica, trampas, etc.
**Efecto especial:** sangrado, aturdimiento, empuje, intimidación, fuego, perforación, infección, etc.
**Notas narrativas:** cómo cambia el comportamiento del jugador o NPC al tenerla.

# Categorías principales de armas

## 1. Armas cuerpo a cuerpo simples

Estas serían las más comunes. No requieren munición y pueden aparecer en casas, almacenes, ruinas o zonas de supervivencia.

* Cuchillo oxidado
* Navaja de bolsillo
* Machete
* Hacha pequeña
* Martillo
* Palanca de hierro
* Tubo metálico
* Palo de madera
* Garrote improvisado
* Lanza casera
* Pico de minería
* Pala
* Tijeras grandes
* Serrucho
* Llave inglesa

Estas armas son buenas para el inicio del evento porque permiten que los NPCs se animen a moverse sin volverlos demasiado peligrosos.

# Reglas útiles para que las armas muevan el juego

Yo usaría estas variables:

**Daño:** cuánto lastima.
**Ruido:** cuánto atrae enemigos o NPCs.
**Amenaza:** cuánto sirve para intimidar.
**Durabilidad:** cuántos usos aguanta.
**Control:** qué tan fácil es usarla.
**Requisito:** qué habilidad mejora su uso.
**Consecuencia:** qué problema genera al usarla.

Ejemplo:

Una **escopeta** tiene daño alto, amenaza alta y ruido alto. Sirve para ganar un combate, pero revela tu posición.

Un **cuchillo** tiene daño medio, ruido bajo y amenaza media. Sirve para sigilo, pero es peligroso acercarse.

Una **pistola sin balas** tiene daño nulo real, pero amenaza alta si el otro no sabe que está vacía.

Una **lanza casera** tiene daño medio, ruido bajo y buen control de distancia. Puede hacer que un NPC cobarde se anime a explorar.
